# 源码课程模板

后续课程统一使用本结构，避免课程退化为文件内容复述。

## 本课完成后能够

- 列出 3 至 5 个可验证的能力目标。

## 前置知识

- 只列本课实际需要的 .NET 和 City 概念，并链接到首次解释位置。

## 先运行，再读代码

- 给出准确命令、参数、预期退出码和关键输出。
- 要求学习者在运行前写下预测。

## 调用链地图

```text
公开入口
-> 内部实现
-> 状态或资源变化
-> 外部依赖
-> 返回调用方
```

## 断点顺序

使用稳定符号名，说明每个断点要观察的对象、线程、状态和调用栈。

## 源码精读

- 按运行顺序组织，不按文件名字母顺序组织。
- 区分公开合同、内部机制和外部框架连接点。
- 明确对象所有权、并发协调和失败路径。

## .NET 基础补给

- 只解释理解当前实现必需的语言或 BCL 机制。
- 立即指出该机制在 City 中解决的具体问题。

## 测试反证

- 指向对应测试类和测试意图。
- 同时覆盖正常、非法、失败、取消、并发和释放中的适用项。

## Lab 实验

- 所有修改限定在 `docs/learning/labs`。
- 每个实验先写预测，再运行，再解释差异。

## 理解检查

- 问题必须要求解释“为什么”，不能只抄类型名。

## 完成标准

- 能画图、能调试、能解释测试、能完成实验，才标记课程完成。
